# Serenity Stay — 리디자인 HTML 초안

## 2026-09-07 · 사진과 움직임 중심 개편

밝은 종이색과 짙은 월넛 브라운, 커진 세리프 제목으로 메인·상세 페이지의 시각적 흐름을 다듬었습니다. 대문 → 숙소 소개·지도 → 장점 → 지역 안내의 구성, 실제 운영 4곳과 부산 Coming Soon, 3개 언어 및 Airbnb 연결은 유지됩니다.

- 대문: 7.2초 진행선, 방향감 있는 사진 전환, 사진별 독립 확대 모션. 이전 사진의 확대가 전환 순간 초기화되던 처리를 대체했습니다. 페이지 이탈·복귀와 언어 전환에도 선택 사진과 사용자의 재생 상태를 보존합니다.
- 스크롤: 사진과 내용은 기본적으로 표시되며, 화면에 들어오면 짧은 이동 효과를 재생합니다. 지원 브라우저의 PC 화면에서는 대문과 숙소 사진에 스크롤 깊이 효과가 추가됩니다. 지원하지 않는 브라우저에서도 사진과 링크는 동작합니다. [CSS animation-timeline 문서](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/animation-timeline).
- 숙소 전환: 다음 사진을 미리 읽고 사진의 방향성 있는 펼침과 설명의 순차 등장으로 전환합니다. 빠른 연속 조작이나 동작 줄이기 설정 변경 시 지난 전환을 취소합니다. 메인의 대표 사진은 여전히 한 장입니다.
- 상세: 큰 대문, 여백이 있는 공간 이야기, 짙은 배경의 사진 투어로 구성했습니다. 지원 브라우저에서는 독립 상세 페이지 이동에도 화면 펼침 효과가 적용됩니다.
- 수정·정리: 가로 썸네일 내부의 중복 숨김 문구가 스크롤 영역 밖으로 빠져나가던 문제를 문구 제거로 해결했습니다. 대문 겹침 순서는 Grid의 z-index로 지정하며 일반 콘텐츠에 고정 좌표를 추가하지 않았습니다. 같은 지역을 선택할 때 지도 문서는 재사용하고 접근성 제목만 갱신합니다.

추가 수정(v6): 사진 자체를 `clip-path`로 완전히 가린 뒤 같은 요소를 관찰하던 처리를 제거했습니다. 일반 모션 환경에서 이미지 로딩은 완료됐지만 관찰 면적이 0으로 유지되는 현상을 재현했습니다. 사진은 항상 표시하고, 관찰 성공 시에만 유한한 이동 효과를 적용합니다. 초기 숨김 클래스·제목 마스크·숨김 해제용 포커스 이벤트를 제거했으며, 실제 이미지 크기를 제공해 상세 갤러리의 로딩 전 공간을 확보했습니다. 가로 숙소 목록과 상세 갤러리의 스크롤바는 숨기고 스와이프·방향키·좌우 버튼을 유지합니다.

확인: 코드 검사, 일반 모션 상태의 메인 사진, 4개 상세 페이지의 사진 14장 표시, 모바일 갤러리와 방향키 탐색, 관찰 기능이 없는 환경의 표시를 점검했습니다. 전체 브라우저·전체 모바일 화면에 대한 전수 검사는 수행하지 않았습니다. 시스템의 ‘동작 줄이기’가 켜져 있으면 모션을 줄입니다. 서버 배포·패키지 설치는 수행하지 않았습니다.

`index.html`을 열면 됩니다. 공유할 때는 `assets`와 `stays`를 포함한 전체 폴더를 전달하세요. 외부 패키지·폰트 서비스·빌드 도구 설치가 필요하지 않습니다.

## 이번 방향

UI 디자인 스킬 `design-first-ui-prompting`을 적용해, 세러니티가 운영하는 공간의 사진·이야기·동네가 중심이 되는 숙소 포트폴리오로 정리했습니다.

- **메인 4영역:** 대문 사진 → 호스트 소개·숙소 포트폴리오·위치 지도 → 숙소 장점 5가지 → 지역 명소 안내.
- **대문:** 사용자 숙소의 실제 사진, 큰 세리프 타이포, 7.2초 간격 크로스페이드, 확대 모션, 이전·다음·자동 재생 정지 버튼.
- **숙소 소개:** 두 줄 목록형 그리드를 제거했습니다. 대표 사진 한 장, 공간별 이야기, 인원·편의시설을 보여주는 큰 소개 영역에서 이전·다음 숙소를 살펴볼 수 있습니다. 대표 사진은 PC·모바일 모두 보조 사진 없이 사진 영역 전체를 사용합니다. 그 아래에는 PC 3개 / 태블릿 2개 / 모바일 다음 카드 일부가 보이는 가로 썸네일 탐색을 배치했습니다. 썸네일은 독립 상세 페이지로 연결되며 Coming Soon은 세 번째 카드이고 예약 링크가 없습니다.
- **운영 브랜드:** 대문과 숙소 소개에 세러니티가 운영하는 집이라는 설명을 넣었습니다. 프라이빗 욕조·햇살 드는 다이닝·밝은 거실·바다 전망 등 실제 공간마다 다른 장면을 소개합니다. 설립 연도·디자이너·호스트 이력 등 미확인 브랜드 이야기는 만들지 않았습니다.
- **상세:** 기존 모달을 완전히 제거했습니다. 각 숙소는 주소가 다른 실제 HTML 페이지입니다. 대문 → 인원·침실·침대·욕실 → 공간 이야기·침대 구성 → 가로 사진 투어 → 편의시설 → 주변 안내·체크인 → Airbnb 예약으로 연결됩니다.
- **모션:** 대문 제목 등장, 그룹별 스크롤 이동, 숙소 전환 시 사진 펼침·확대, 지원 브라우저의 스크롤 깊이·페이지 전환. 스크롤 등장 효과를 기다리는 동안 사진을 숨기지 않으며, 시스템의 동작 줄이기 설정을 존중합니다.
- **지역 카드:** 이미지에 호버하거나 키보드 포커스를 주면 소개 문구와 그라데이션이 걷히고 사진·탐색 안내가 드러납니다. 마우스 호버 효과는 정밀 포인터 환경에만 적용되며 터치에서는 기본 소개를 유지합니다. 이미지 바깥에도 도시명을 표시해 맥락이 사라지지 않습니다.
- **지도:** 메인에서 숙소별로 주변 지역 샘플 지도를 선택할 수 있습니다. 숙소 소개를 넘기면 해당 지도도 연결됩니다. 상세 페이지에서는 기존 관광지 사진을 해당 숙소 주변의 샘플 지도로 교체했습니다.
- **언어:** 영어 기본, 한국어·중국어 간체 지원. 선택 언어만 로컬에 저장합니다.
- **예약:** 실제 4개 Airbnb 페이지로 연결합니다. 가격·예약·결제·호스트 문의는 Airbnb에서 진행합니다. 이메일, 구독, 회원가입, 사이트 내 결제는 없습니다.

전체 페이지는 스크립트 실행 전에 이미 완성된 영어 HTML입니다. JavaScript 없이도 숙소 소개, 상세 페이지 이동, 모든 사진 열람과 예약 링크가 작동합니다. 언어 전환·숙소 소개 전환·지도 선택·자동 슬라이드·모바일 접이식 메뉴·추가 모션은 JavaScript를 사용합니다. 사진과 글꼴은 외부 CDN 없이 표시되지만, 지도는 OpenStreetMap에 접속할 수 있어야 표시됩니다.

## 수정 및 숙소 추가

원본은 `content.js`, `app.js`, `styles.css`, `build.cjs`입니다. `index.html`과 `stays/*.html`은 생성 결과이므로 직접 수정하면 다음 생성 때 덮어써집니다. 지도와 번역은 `content.js`, 공유 사진 탐색과 템플릿은 `app.js`에 있습니다.

1. `content.js`의 `stays` 배열에 숙소를 추가합니다. 배열 순서가 목록 순서입니다. 각 문구는 `[영어, 한국어, 중국어 간체]` 형식입니다.
2. 운영 숙소는 `status: "open"`과 정확한 Airbnb `listingId`, 확인한 정원·침실·침대·욕실, 사진 경로 등을 입력합니다. `signature.title`과 `signature.text`는 메인에서 소개할 해당 공간만의 장면입니다. `map`은 지도 설정입니다. `id`에는 영문 소문자·숫자·하이픈만 사용하세요.
3. 오픈 예정은 기존 `busan-next`와 같이 `status: "coming-soon"`을 사용하며 예약 정보와 미확정 날짜를 넣지 않습니다. 현재 예고 카드 문구·이미지는 부산 신규 숙소용입니다. 다른 도시의 오픈 예정 숙소를 추가한다면 해당 문구·이미지도 함께 확장해야 합니다.
4. 사진 파일을 `assets`에 넣고 아래 명령으로 HTML을 다시 생성합니다.

```sh
node build.cjs
node check.cjs
```

운영 숙소를 추가하면 카드와 별도 상세 HTML이 함께 생성됩니다. 실행 중인 페이지에는 자동 새로고침 기능이 없으므로 수정 후 새로고침하세요. 숙소를 삭제·이름 변경한 경우 이전에 생성된 상세 파일을 자동 삭제하지 않으므로, 공개 전 오래된 파일의 유지 여부를 사람이 확인해야 합니다.

## 지도 샘플과 교체 위치

사용자가 정확한 위치를 확인하기 어려우면 샘플로 진행해도 된다고 허용했습니다. 따라서 지도는 **숙소의 정확한 위치를 확인한 결과가 아닙니다**. 미아·수유 / 연신내 / 송도 주변 지역을 보여주는 데모이며, 정확한 숙소 핀이나 주소를 넣지 않았습니다. 이 안내를 메인·상세의 지도 위아래와 접근성 제목에 표시합니다.

`content.js` → 각 운영 숙소 → `map`에서 다음 값을 수정할 수 있습니다.

- `lat`, `lng`: 지도 중심의 위도·경도. 현재 값은 주변 지역 샘플 중심입니다.
- `span`: 보여줄 주변 범위. 경도 방향 좌우 범위이며, 위도 방향은 이 값의 0.65배로 계산합니다.
- `label`: `[영어, 한국어, 중국어]` 지도 지역명.
- `kind: "area-sample"`: 현재 지도 성격. 이 값만 바꾼다고 정확한 위치 핀으로 전환되지는 않습니다.

공개 가능한 정확한 주소·좌표를 확정하면 `app.js`의 `mapUrls()`에서 마커 포함 여부를 반영하고 `copy.mapNotice`, `copy.mapSample`, `copy.mapTitleLabel`도 실제 안내에 맞게 교체하세요. 미확인 좌표를 숙소 주소로 표시하지 않도록 일부러 자동 핀을 넣지 않았습니다.

지도는 [OpenStreetMap 공식 임베드 방식](https://wiki.openstreetmap.org/wiki/Export#Embeddable_HTML)을 사용합니다. iframe은 지연 로드하며 referrer를 보내지 않습니다. 지도 표시 시 방문자의 브라우저가 OpenStreetMap에 접속하므로 네트워크 및 지역별 접근 정책의 영향을 받습니다. 서비스 차단·장애·오프라인에서도 숙소명·지역 안내·큰 지도 링크는 페이지에 남습니다. 실제 중국 현지 네트워크에서의 지도 표시 여부는 확인하지 않았습니다. API 키와 패키지 설치는 필요하지 않습니다.

## 사진과 디자인 참고

숙소 사진은 사용자가 운영하는 곳으로 제공한 Airbnb 페이지에서 가져왔습니다. 로고는 사용자 제공 우드 로고를 사용하며 원본 파일을 보존했습니다. 숙소 사진의 공개 사용 권한은 운영자가 최종 확인해야 합니다. 외부 숙소 사이트의 사진·코드·로고는 사용하지 않았습니다.

Atelier Escape의 [독립 상세 페이지](https://atelierescape.com/bailey)를 공간 소개·사진 투어·편의시설·위치·외부 예약 순서의 참고로 사용했습니다.

도시 사진은 숙소 전망이 아닌 관광지 아카이브입니다. 사이트 하단 출처 안내에도 저자·원본·라이선스·촬영 연도와 표시 크롭 사실을 기재했습니다.
